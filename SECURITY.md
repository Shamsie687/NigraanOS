# NigraanOS — Security Policy

## Reporting a Vulnerability

If you discover a potential security vulnerability in NigraanOS, please report it privately rather than opening a public GitHub issue.

Contact: **nigraanos.admin@gmail.com**

Please include a description of the issue, steps to reproduce it, and any relevant technical details. Do not include real user data, passwords, access tokens, or other sensitive information.

## Security Approach

NigraanOS is a developing civic technology project. Its security approach includes:

- Supabase Authentication and database Row-Level Security policies.
- Permission-controlled access to Operations functionality.
- Time-limited authorization for protected MCP operations.
- Private storage and controlled access for incident evidence.
- Human oversight of AI-generated recommendations.
- Environment-based management of application secrets.

Security controls continue to be reviewed and tested. This document does not guarantee that the platform is free of vulnerabilities or suitable for production government deployment.

## Responsible Disclosure

Please allow a reasonable opportunity to investigate and address reported vulnerabilities before publicly disclosing them.

Avoid accessing, modifying, or downloading other users' information while investigating potential issues.

## Scope

This policy applies to the NigraanOS open-source project and its associated application components.

NigraanOS is a hackathon-stage project and is not an officially deployed government service.
